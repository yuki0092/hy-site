Privacy Policy

App: LunaMixer: Per-App Volume (Japanese: 個別音量) / Publisher: HY Studio / Last updated: 11 August 2026

日本語

This policy sets out how the mobile app "LunaMixer" (the "app") handles user information.

1. Information collected and stored

The app collects no user information at all. Nothing reaches the developer, and nothing is sent to any external server. There is no account, no sign-in, and no email address to enter.

The only things the app stores are these settings. All of them stay on the device and never leave it.

  • The theme you picked (colour and light/dark)
  • The volume you set for each app
  • A record of whether first-run setup has been completed

2. Network use

The app shows no adverts and contains no analytics or crash-reporting.

The app does hold Android's internet permission (INTERNET). It is needed to reach Android's own wireless debugging endpoint. That endpoint is on the same device the app is running on. The app never connects to any external server, including any server of the developer's.

Wi-Fi is required during first-run setup because Android only makes wireless debugging available while a Wi-Fi connection is active. That Wi-Fi does not have to reach the internet.

3. Use of the Accessibility API

The app uses Android's Accessibility service. It is used for exactly one purpose: reading the six-digit pairing code shown on screen during first-run setup.

It is needed because the pairing code stops working the moment you leave the screen that shows it. There is no way for you to write the digits down and type them into the app, so reading them off the screen is the only route.

What it can see and do is limited as follows.

  • It is restricted to the screens of Android's Settings app (android:packageNames="com.android.settings"). It cannot read the screens of any other app.
  • It never operates your screen — no taps, no text entry, no scrolling. It only reads.
  • It runs only while first-run setup is waiting for a pairing code.
  • The moment pairing succeeds, the app switches this service off itself. You do not have to turn it off by hand.
  • The six digits it reads are used to connect and are neither stored nor transmitted.

The prompt "Allow LunaMixer to have full control of your device?" is the wording Android shows for every app that uses Accessibility. It is not a description of what this app does.

4. Other permissions

  • Display over other apps (SYSTEM_ALERT_WINDOW) — to show the volume bubble and panel while you are using other apps.
  • Query installed apps (QUERY_ALL_PACKAGES) — to show the name and icon of each app that is playing audio. This is used for display only and is neither stored nor transmitted.
  • Notifications (POST_NOTIFICATIONS) — to report setup progress and to show that volume control is running.
  • Foreground service (FOREGROUND_SERVICE and related) — to keep the bubble on screen while other apps are in use.
  • Network state (ACCESS_NETWORK_STATE) — to detect whether you are on Wi-Fi, so setup can say so.

5. Deleting your data

Everything the app stores is on your device. Uninstalling the app deletes all of it. There is no need to ask the developer to delete anything, because the developer holds nothing.

The pairing registered on your device during setup can be removed by you at any time under Settings → Developer options → Wireless debugging.

6. Children's privacy

This app is not directed at children under 13.

7. Disclaimer

The app is a tool that sets per-app volume using Android's own developer features.

  • Using the app requires Android's "Developer options" and "Wireless debugging" to be switched on. Please decide for yourself whether leaving those on is appropriate for your device. In particular, if you leave "USB debugging" on, take care not to connect to computers or USB devices you do not trust.
  • Some apps produce sound in a way that cannot be adjusted this way. Operation with every app is not guaranteed.
  • Setup steps and behaviour may differ depending on the device model, Android version, and manufacturer changes.
  • The developer accepts no liability for any damage arising from use of the app, except in cases of wilful misconduct or gross negligence.
