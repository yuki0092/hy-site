LunaMixer: Per-App Volume

One sound at a time.

One-time setup, so every app that is playing gets its own volume. No computer, no cable — just Wi-Fi for the first run, all on this phone.

Coming soonGoogle Play
No computer No root No extra app Wi-Fi first run only

What this app does

The usual per-app volume apps switch the whole device volume to match whichever app is in front. LunaMixer sets a separate volume for each app that is playing, all at the same time.

!

If you have a Galaxy

On Galaxy (Samsung) phones, the built-in "Sound Assistant" may already do this. Trying that first is probably quicker. This app is for phones without an equivalent.

Why does it need a special setup?
The volume controls this app uses cannot be reached through ordinary Android settings, so the first connection is made over wireless debugging. Leaving USB debugging on afterwards keeps that connection alive even with no Wi-Fi around. Everything used here is a standard part of Android.

Install from Google Play

Google Play → LunaMixer
ImportantTap Allow when it asks about notifications. Later on, the six-digit code is typed into this app's notification.
  1. Get LunaMixer from Google Play.
  2. Open the app and tap Start.
  3. Tap Allow when it asks about notifications.
More about this screen

Notifications have to be allowed. In step 5 you type the six-digit pairing code into this app's notification. Refuse notifications and that box never appears, so setup cannot be finished. If you have already refused, allow it again under Settings → Apps → LunaMixer → Notifications.

That is setup finished

Back in the app, Show bubble can now be tapped.

From here on, it all happens in the bubble.

The sliders open from the bubble floating over your screen, not from the app itself. Next time, all you do is tap Show bubble.

Using it

  1. Open the app and tap Show bubble.
  2. Drag the round bubble wherever you want it.
  3. Tap the bubble to open the list of apps that are playing.
  4. Move a slider and that app's volume changes as you go.
↘
Finer control at low volumes

Most adjustments land between 0 and 30%, so the bottom 60% or so of the slider is given to that range.

To put everything back: tap Stop volume control in the panel, or close both the app and the bubble. Volumes return to normal a few seconds later.

?

If something goes wrong

Wireless debugging will not turn on
Connect to Wi-Fi first. A Wi-Fi network with no internet access is fine.
The notification for the code never appears
Notifications are probably not allowed. Check Settings → Apps → LunaMixer → Notifications. The notification appears the moment you tap [Open Developer options] inside the app.
The code was sent but nothing connects
The code has probably changed. Going home or opening another app changes the digits (pulling down the notification shade does not). Opening the app tells you the current reason; start the pairing again from the beginning.
It was working, now it says "Not connected"
Both USB debugging and wireless debugging probably ended up off. Get on Wi-Fi, turn wireless debugging back on, and tap "Turn volume control back on".
The volumes went back to normal on their own
Closing both the app and the bubble returns everything to normal after a few seconds. Leave the bubble showing to keep your settings in effect.
One app ignores the slider
A few apps produce sound in an unusual way — some games in particular — and cannot be controlled this way.
!

If you leave USB debugging on

1
Always read the prompt when a new computer connects
You will be asked "Allow USB debugging?". If you were not expecting it, refuse.
2
"Always allow" only for computers you trust
Once allowed, that computer may connect again without asking.
3
Avoid unknown USB devices, chargers and cables
If a public charging point brings up a connection prompt you did not expect, always refuse.

If it bothers you, turn USB debugging back off when you are not using it. Next time, get on Wi-Fi, turn wireless debugging on, and tap Turn volume control back on.
